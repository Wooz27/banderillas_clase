# AGENTS.md

Librerias implementadas en el proyecto:

- **streamlit** — framework de la aplicación: interfaz web, tablas editables y pantallas
- **SQLAlchemy** — ORM: conexión, sesión y modelos de la base de datos SQLite (`costos.db`)
- **pandas** — manejo de datos: DataFrames de las tablas editables y sus cálculos
- **plotly** — gráficas y estadísticas
- **streamlit-option-menu** — menús con íconos (sidebar y secciones internas)
- **streamlit-extras** — componentes de UI extra para dashboards

Instaladas vía `requirements.txt` en el entorno `.venv/` (uv).
